# Mockups

The key-screen mocks for this UX run live as a published Claude design canvas, not as files here:

**https://claude.ai/artifact/MimSyEDb4rZ8DbZk3R3emy** — *SampleLoop UI — Six Journey Screens*

The canvas is private to its owner until it is shared from the page's Share menu.

| Artboard | Journey | Surface | Interactive beat |
|---|---|---|---|
| `Main.dc.html` | UJ-1 | Browse + Kit builder (Designer, desktop) | Submit the Kit → 7 held pieces named, 1 unfulfilled Sample with alternatives |
| `Handover.dc.html` | UJ-2 | Handover (Staff, 390px counter phone) | Toggle a piece off → Hold released, commit bar re-counts |
| `Return.dc.html` | UJ-3 | Partial return (Staff, 390px counter phone) | Condition toggle with no default → save blocked until every ticked piece is assessed |
| `Extensions.dc.html` | UJ-4 | Extension queue (Staff, desktop) | Competing Hold shown inline before the decision; approve one, decline one |
| `Dashboard.dc.html` | UJ-5 | Dashboard + chase list (Staff, desktop) | Copy a Reminder Draft → Studio settles into reminded; one Studio already suppressed |
| `Case.dc.html` | UJ-6 | Case resolution (Manager, desktop) | Record charge → waive with reason → resolve with an outcome; amount never erased |
